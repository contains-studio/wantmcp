to indicate that those clients can be used with The Want MCP. The Want MCP is not affiliated with,
sponsored by or endorsed by any of them.

These files are **not** covered by this repository's MIT licence. If you reuse this code, do not
reuse these marks without following each owner's brand guidelines.

Each file is exactly as downloaded from the source below (checked 25 November 2026). To stop showing
one, delete its `logo` line in `apps/web/app/lib/brands.ts` (the client then shows as its name) and
delete the file.
